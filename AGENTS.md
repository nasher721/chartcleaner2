## Learned User Preferences

- Prefers the medical chart cleaner to be easy to run from the Mac (Automator app / Dock-friendly flow, not only terminal).
- Wants to keep real clinical content while stripping supplementary noise, boilerplate, and EMR chrome.
- When asking to implement or fix something, expects concrete changes rather than extended discussion.

## Learned Workspace Facts

- Core cleaner lives in `medical_cleaner.py` beside `config.json`; rules (regex lists, headers, `nlp_allow_list`, duplicate-note settings) stay in JSON, not hardcoded in Python.
- Every builtin stage is option-driven now: whitespace/bullets/headers have option groups (`whitespace`, `bullets`, `header_options` in config.json), the four regex stages honor `stage_options.<stage_id>.case_sensitive` and `stage_options.<stage_id>.enabled`, and five opt-in stages exist (`unicode_normalize`, `timestamps` → `timestamp_removal`, `sections` → `section_filter`, `caps_normalize`, `line_length`). Defaults all reproduce pre-option behavior — `tests/golden` depends on that; `tests/test_options.py` covers each group.
- Clipboard workflow uses a `clean-chart` helper script beside the app; `Clean_Medical_Chart.applescript` resolves the parent folder of the app/script and runs that `clean-chart`, then shows a notification (re-run `osacompile` after editing the applescript).
- Stack includes Presidio plus spaCy `en_core_web_sm`; downloading or verifying spaCy models requires `pip` or `uv` available in the environment (spaCy’s installer errors if neither is found).
- Pipeline targets Epic-style exports: strip line-level metadata and boilerplate, optional structuring for LLMs, and configurable near-duplicate note folding per `config.json`.
- **Windows:** Run `install.bat` once (CMD only, **no admin** — venv + packages live entirely under this folder). If PowerShell is allowed, `install.ps1` or `powershell -ExecutionPolicy Bypass -File .\install.ps1` is equivalent. Then `clean-chart.cmd` (CLI) or `Clean_Medical_Chart.cmd` (double-click clipboard, no PowerShell). Need **Python 3.10+** without elevation: use [python.org](https://www.python.org/downloads/) installer with **“Install for all users” unchecked** and **“Add python.exe to PATH”** checked (installs under your profile). Copy the whole project folder to Desktop/USB if the machine allows that.
- **Mac without admin:** If `python3` is already 3.10+ (IT image, Homebrew in your home, etc.), run `./install.sh` from a folder you own; no sudo. If Python isn’t available, IT must install it or you use a machine where you’ve already run install, then copy the folder (same Mac + same Python major.minor as the venv’s `pyvenv.cfg` home, or re-run `install.sh` after copy).
- **Local AI summary (Clean page):** `chartcleaner/summarizer.py` is the only entry point app code uses — `summarize(chart, cfg, client=None)` with an injectable client so tests never touch the network (`tests/test_summarizer.py`, FakeClient). Config group `local_llm` (DEFAULT_LLM in summarizer.py), presets in SUMMARY_PRESETS. Ollama IS installed on Nash’s Mac as of 2026-09-20 (`brew install ollama`, daemon via `brew services start ollama`, model `llama3.1` pulled, live 100%-grounded summary verified). `LocalLlmClient` refuses non-loopback base_urls (loopback guard) — don’t relax it.
- **Ask this chart (Clean page, v2.3.0):** `chartcleaner/chart_qa.py` — `ask_chart(question, chart, cfg, client=None, history=None)` mirrors the summarizer pattern (injectable client, same `local_llm` config group, same LlmUnavailableError/NoModelError); per-answer grounding via `verify_clinical_grounding`. Turns live only in `CLEAN_STATE["qa"]` (reset on every new clean); prompt embeds last 3 turns (MAX_HISTORY_TURNS).
- **Batch page (`/batch`, v2.3.0):** `chartcleaner/batch.py` — `run_batch(paths, cfg, custom_dir=None)` returns per-file `BatchResult` (errors isolated per file, `cleaned` + slim `stages` included so batch runs still feed Statistics). The old Clean-page "Batch folder" expansion was retired in favor of this page (multi-file upload or folder path, per-file + .zip downloads; `store.prune_exports` now prunes `*.zip` too).
- **Integration service layer:** `chartcleaner/service.py` is the one entry point integrations (REST, MCP, hotkeys, clipboard watcher) use — `clean()`, `abbreviate()`, `ask()`, `format_output()`; runs record history as `api:<caller>`. `Pipeline.run(track_changes=True)` records per-change provenance in `details["changes"]` (in memory only — `to_history_dict` strips it); `details["rule_hits"]` (rule_id → count) is always recorded. New builtin stages declare `STAGE_ANCHORS` in `engine.py` so saved stage orders place them correctly. Roadmap: `docs/improvement-plan.md`.
- **Abbreviation safety:** `chartcleaner/abbreviation_safety.py` + `abbreviation_do_not_use.json` (meaning-aware: an entry applies only when the full term matches its `meaning` regex; compounds like U/hr are checked per part). Block-level hits in the bundled CSV are never applied by the matcher, nor are one-letter abbreviations with several CSV meanings (x, K, N, …) or `a` (`_unclear_letters`); a term followed by its own abbreviation in parentheses collapses ("SAH (SAH)" → "SAH"); a custom entry with `"acknowledged": true` (set via the "I understand" override) re-enables one. `normalize_settings` keeps optional `acknowledged` and `pack` fields. Text-expander export: `chartcleaner/expander_export.py` (`--export-abbreviations`).
- **Abbreviation tools (Phase 2):** `abbreviations.expand()` (Pipeline mode `"expand"`, `--mode expand`, `service.expand`) is case-sensitive, leaves ambiguous abbreviations (several distinct meanings; spelling variants count as one) unless `abbreviations.expand_prefer` picks one, and skips one-letter/plain-lowercase forms, ALL-CAPS lines and `[[Tn]]` tokens. `abbreviations.scope` ({"mode": "only"|"except", "sections": [...]}) is honored inside `abbreviate()` via `section_parser`. Packs: `chartcleaner/packs/abbreviations/*.json` + `abbreviation_packs.py` (entries tagged `pack`; regenerate with `scripts/build_abbreviation_packs.py`). Phrase suggestions: `phrase_miner.mine()`; dismissed phrases live in `abbreviations.rejected_suggestions`. The Clean page runs with `track_changes=True` to power the result's Abbreviations tab.
- **Testing gotcha:** the NiceGUI `user` fixture runs `app.py` before the test body. Pages live in `app_pages/` (one module per page, shared helpers/imports in `app_pages/common.py`, update checks in `app_pages/updates.py`); rebindable names (`CONFIG_PATH`, `PREFS`, `CUSTOM_DIR`) are read only as `common.X`, so a UI test that saves config does `monkeypatch.setattr(common, "CONFIG_PATH", tmp)`. Routes are registered in `app.py`'s `ROUTES` table, not with `@ui.page` decorators (the harness re-runs `app.py` against already-imported page modules); `test_page_modules_read_rebindable_names_through_common` enforces both.
- **Cleaning stages (Phase 3):** opt-in condensers live in `chartcleaner/compactors/` (`labs`, `meds`, `vitals`, `neuro`, `imaging`, `hospital_day`), each with `DEFAULTS` + `run(text, cfg, ctx)`; registered in `engine.py` (BUILTIN_STAGE_IDS, STAGE_LABELS, STAGE_KINDS, `STAGE_ANCHORS`), `stages.py` RUNNERS/KIND_TO_RUNNER, `config_validator.py`, and the Pipeline page via declarative `STAGE_FORMS` in `app.py`. Safety rule: rewrite a block only when every line parses. Regex stages honor `stage_options.<sid>.exceptions` ("Never remove this"). `delta_engine` prunes only sentences that literally repeat an earlier note. Also: `note_type.py` (mapping in prefs `note_presets`/`note_auto_apply`), `rule_health.py`, `rule_examples.py`.
- **Tests never touch `data/`:** `conftest.py` autouse fixture redirects run history, config backups, exports, token maps, audit hits and rule examples to tmp. New pages go in `app_pages/<name>.py` and get a line in `app.ROUTES`.
- **Integrations (Phase 4):** all go through `chartcleaner/service.py`. Local REST API `chartcleaner/api.py` (registered on the NiceGUI app; loopback + Origin check + 5 MB cap + bearer token in `data/api_token`, mode 600). MCP server `chartcleaner/mcp_server.py` (mcp 2.x `MCPServer`, stdio only; launchers `clean-chart-mcp[.cmd]`). `prompt_templates.py` (config `prompt_templates`), `exporters.py` (docx via stdlib, Markdown/notes folder, smartphrase), `clipboard_watcher.py` (prefs `clipboard_watcher`; never started under NICEGUI_USER_SIMULATION). CLI: `--stdin/--stdout/--preset/--prompt/--watch-clipboard`, `--format smartphrase|docx`. macOS Quick Actions: `integrations/macos/make_quick_actions.py` (`./install.sh --services`); Windows hotkeys `integrations/windows/chart-cleaner-hotkeys.ahk`; browser extension `integrations/browser-extension` (MV3, loopback-only; JS tests `node --test request.test.mjs`). Setup guide: `docs/integrations.md`. `CHARTCLEANER_DATA_DIR` relocates `data/`.
- **Phase 5:** `fact_check.py` runs on every clean (`result.fact_check`; summarizing stages must be listed in `fact_check.BY_DESIGN_STAGES` or their drops show as unexpected). Token maps are encrypted via `secure_store.py` (tests force the `file` key backend in tmp); retention in `prefs.retention_days`. `trends.py` (lab trends / med changes across notes). Roadmap section "Phase 5" in `docs/improvement-plan.md`.
- **Phase 6 (UI):** Clean page is two columns (chart | result) with the AI in a right drawer; result tabs Output / Review / Insights; tests use markers (`run-clean`, `copy-as`, `copy-<fmt>`, `review-diff`, `sel-remove|replace|abbreviate|keep|more`, `selection-bar`, `inbox`, `fact-check`, `palette-button`, `palette-input`). `common.shell(..., wide=, commands=, shortcuts=, actions=)` owns the command palette and keyboard shortcuts (`shortcut_matches`). Quasar `bg-grey-*` + `dark:` doesn't switch in dark mode — use the `cc-panel` class. `user.find()` only returns visible elements; menu items need markers (their text sits on a child section).
- **Phase 6 (back end):** `recent_charts.py` (encrypted `store.RECENT_DIR`), `rule_inbox.py`, `rule_preview.py`, `regression_set.py` (`store.KNOWN_GOOD_DIR`), `timeline.py`, `stage_cache.py` (`Pipeline.run(cache=)`, `service.result_cache()`; a config key may be in `OWNED_KEYS` only if exactly one stage reads it), `Pipeline.stage_io()`, `service.restore()`. conftest redirects the new store paths. Roadmap: "Phase 6" in `docs/improvement-plan.md`.
- **Phase 7 (trust):** `fact_check.verify_output()` checks AI output value by value (`SummaryResult/QaResult.facts`); `FactReport` also carries `meaning` (dropped negation / switched side on rewritten lines; negation abbreviations come from the CSV), `introduced` (numbers new to the chart) and `implausible` (`plausibility.py`). Every `KNOWN_CONFIG_KEYS` group needs a validator (parametrized test).
- **Phase 7 (clinical/workflow):** verbatim extractors `problems.py`, `devices.py`, `micro.py`, `overnight.py` (+ score trends in `trends.py`), dates via `chart_dates.py` (reference date = latest dated line). `service.insights()`; `daily_note.py`; `patients.py` + `batch.run_texts`; `note_templates.py` (config `note_templates`). - **Phase 10:** insights `safety` (`safety.py`: allergies, code status, isolation, weight/height, antithrombotics — latest line verbatim, `changed`/`not stated`/`removed by cleaning`; the Clean page passes `safety.removed_lines(result.fact_check)`) and `stale` (`stale.py`: time-bound latest-note lines unchanged across ≥3 notes) join `service.INSIGHTS`. Insights read the *cleaned* text, so patterns must also match the abbreviated forms (ALLG, Hep gtt, tmrw). Copy guard: prefs `copy_guard` makes Clean-page copies ask first when `fact_check.status == "alert"` (`guarded_copy`, ack resets on every clean). The Code Status metadata rule is history-only since Phase 12 (live "Code status: DNR" statements survive; strict pattern kept in the Pipeline stage description).
- **Phase 11:** insight `conflicts` (`conflicts.py`: latest-note line pairs that can't both be true — left vs right, lesion/deficit same side, NPO vs eating, full code vs DNR, no AC vs active anticoagulant, allergy vs med, afebrile vs fever; verbatim, never edits). - **Phase 12:** `stages.py` is a facade over `stage_core` (shared regex machinery; patch `stage_core.SLOW_RULE_MS`/`MAX_TRACKED_CHANGES`, not `stages`), `stage_regex`, `stage_cleanup`, `stage_sections`, `stage_dedup`, `stage_nlp` (all public names re-exported). `store.py` is a facade over `store_history`/`store_prefs`/`store_data` — path constants live ONLY on `store` (conftest + tests patch `store.X`); submodules read them via a lazy `from . import store` accessor. `config_validator.py` is `ConfigValidator(ValidatorBase, Regex/Options/Review/PipelineSchemaMixin)` from `config_schema_*.py`. Insight order is canonical in `service.INSIGHT_ORDER` (`INSIGHTS` aliases it; `format_output` renders it minus `trends`). Census cards carry `delta/delta_total/delta_since` vs the previous stored chart (`census.changed_since`, delta_engine sentence semantics) plus Copy/Download as text/Markdown via `exporters.to_markdown`; census stays off REST/MCP (reads every stored chart — reason in `docs/integrations.md`). `vitals_summary.window_hours` (0 = all; header date-row windowed, else min/max/last fallback; `int` control in `STAGE_FORMS`). Abbreviation CSV has a `Sections` column (`;`-joined; legacy files without it still import). Batch one-liners stream via `summarize(on_token=)` into a dict the progress timer reads (workers never touch UI). Watcher focus-pause dropped with reason in `clipboard_watcher.py` (server can't see focus; own-output digest already prevents loops). `rule_health` falls back to run-level `lines_before` so slow rules report `slow`, and slow rows have the one-click Remove. Roadmap: "Phase 12" in `docs/improvement-plan.md`.
- **Phase 13 (a11y + resilience + validation):** `app_pages/a11y.py` is the accessibility layer — `sr_only`, `skip_link`, `landmark`, `status_region`, `activate_on_key` — applied inside `common.shell` (skip link, `main`/`navigation`/`banner`/`contentinfo`, `aria-current` on the active nav link). `design_system.status_tag` makes clickable pills keyboard-operable when `on_click` is given; `common._diff_table_start` gives the diff tables a `cc-sr-only` caption + column headers, and the review diff's change spans are `tabindex=0 role=button` with `REVIEW_KEY_JS` for Enter/Space. Routes register with `language="en"` (sets `<html lang>`). `common.guarded(page_fn)` wraps every `app.ROUTES` entry: an unexpected page error renders `_render_error_page` (recovery screen, traceback to `data/app.log`) and re-raises the original if the recovery itself fails — pages still handle their own expected errors. `store_prefs._coerce_pref` keeps a stored pref only when its shape matches the default (wrong type → default; NaN/Inf → default for numbers), and `engine.load_config` passes `parse_constant=_reject_constant` so NaN/Infinity are refused. Tests: `tests/test_a11y.py`, `tests/test_error_boundary.py`, `tests/test_validation.py`. Roadmap: "Phase 13" in `docs/improvement-plan.md`.
- **Review hardening (2026-10-15):** `chartcleaner/host_guard.py` (`LoopbackHostGuard`) is added in `app.main()` when bound to loopback — the UI refuses non-loopback `Host` headers (DNS rebinding); it is not installed under the test harness, so test it with Starlette's `TestClient` (`tests/test_host_guard.py`). `local_llm` talks to Ollama only through `local_llm._urlopen` (a no-proxy opener — plain `urlopen` would send chart text to `HTTP_PROXY`); tests patch `local_llm._urlopen`. Token maps are one file per run (`tokens-<YYYYmmdd-HHMMSS>-<µs>[-NNN].enc`, still sorting oldest-first). `secure_store` creates a keychain key only on "item not found" (exit 44), never with `-U`, and `decrypt` also tries `data/.datakey` left by a keystore fallback. `chart_dates`: month names must be real spellings (not "Decadron 4"), 2-digit years pivot to 19xx, and `reference_date` ignores dates after today.
- **Performance (2026-10-15):** with no `nlp_redaction.score_threshold`, `stage_nlp` runs spaCy NER only (tok2vec/tagger/attribute_ruler/lemmatizer disabled, lemma = lowercased token via the `chartcleaner_lower_lemma` pipe; en_core_web_sm's NER has its own embeddings, so entities are identical) — a threshold keeps the full pipeline. The engine cache key is built only in `stage_nlp._engines`; the startup warm-up and Doctor call `stage_nlp.warm(cfg)` so they never evict the engine a clean uses. Fact-check facts are line-local (`fact_check._S` is whitespace minus newline) so `FactTracker` counts per line and rescans only lines a stage changed — keep new fact patterns on one line. `store_history.load_runs` parses only appended bytes (head/tail fingerprint detects rewrites; returns fresh dicts). The Clean page builds the Review diff HTML in the worker (`CLEAN_STATE["review_html"]`, cleared with the result). Tests: `tests/test_performance.py`.
