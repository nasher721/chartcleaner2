# Impeccable — Design Context

> The "Clinical Precision" direction was replaced on 2026-10-12 by a
> Nothing-inspired system. The users, brand personality and design principles
> below survived; the palette, typography and component language did not.

## Users
Physicians, residents and clinical support staff who clean Epic-style chart
exports on their own machines (Mac/Windows, local-first, privacy-sensitive).
They use Chart Cleaner mid-workflow: paste a chart, verify every change in a
diff, copy a cleaned/garbled note, or tune rules. They often work at odd hours.
Their core emotion: **I must be able to trust what this tool removed** —
verification beat speed. A second tier: power users who maintain pipelines,
scripts and stats.

## Brand Personality
Three words: **precise, quiet, instrument-grade**.
Voice of a surgical tray: everything has a place, nothing decorative without
function, calm confidence rather than friendliness. NOT playful, NOT a
consumer SaaS, NOT a chat app.

## Aesthetic Direction — Nothing design system
Swiss typography crossed with industrial design (Braun, Teenage Engineering).
Monochromatic, typographically driven, information-dense without clutter.

- **Subtract, don't add.** Every element earns its pixel.
- **Structure is ornament.** Expose the grid, the data, the hierarchy itself.
- **Monochrome is the canvas.** Colour is an event, not a default — except
  where it encodes data status.
- **Type does the heavy lifting.** Scale, weight and spacing create hierarchy —
  not colour, not icons, not borders.
- **Both modes are first-class.** Dark = OLED-black instrument panel (default).
  Light = warm off-white printed technical manual. Identical accent, status
  colours, fonts, type scale, spacing and shapes.
- **No shadows, no blur, no gradients, no spring easing.** Flat surfaces,
  hairline separation, subtle ease-out (`cubic-bezier(.25,.1,.25,1)`).

### Type roles — four levels, no more
| Role | Face | Where |
|------|------|-------|
| Display | **Doto** (dot-matrix) | Page titles and hero metric numerals — 30px+ only |
| Heading / body | **Space Grotesk** | Card titles, prose, descriptions |
| Label / data / UI | **Space Mono** | ALL-CAPS micro-type, nav, buttons, tables, inputs, numerals |

Fonts are **self-hosted** in `chartcleaner/static/fonts` (8 woff2 files,
~89 KB). The app is offline-first and `app.py` strips external font CDN links
from served HTML, so a Google Fonts `<link>` is not an option.

### Colour
The grey scale *is* the hierarchy: `--text-display` (100%) → `--text-primary`
(90%) → `--text-secondary` (60%) → `--text-disabled` (40%).

Status colour is applied to the **value**, never to a label or a row
background — and it is how the diff reads at a glance:
- `--nd-accent` **#D71921** — removed text, destructive actions, ungrounded values
- `--nd-success` **#4A9E5C** — inserted/kept text, healthy counts
- `--nd-warning` **#D4A843** — needs review, fact-loss cautions
- `--nd-interactive` **#007AFF / #5B9BF6** — links and picker values only

Data visualisation differentiates with **opacity before colour**
(`opacity_ramp()`), so charts stay monochrome. The signature data visual is the
**segmented bar** — discrete square blocks with 2px gaps (`SegmentedBar`), always
paired with a numeric readout.

### Memorability
Numbered section system (`01 CLEAN` … `08 DOCTOR`), a small monochrome SVG brand
mark, square-indicator status tags, and one bracketed active nav item
(`[ 05 STATISTICS ]`).

## Where the system lives
- **`app_pages/design_system.py`** — the single source of truth: tokens,
  `@font-face` declarations, the entire stylesheet, and the components
  (`stat_chip`, `SegmentedBar`, `status_tag`, `chart`, `tone`, `opacity_ramp`).
- `app_pages/common.py` — `shell()` composes the frame (header, horizontal text
  nav, drawer, footer, page header) and re-exports the helpers to every page.
- Pages keep reading the historical `--cc-*` variable names; those are now thin
  aliases onto the `--nd-*` tokens, so one token change reaches all screens.

### Two cascade gotchas worth remembering
1. **Quasar's colour utilities live in `@layer quasar`.** For `!important`
   declarations the *first*-declared layer wins, so the colour overrides sit in
   `@layer theme` (declared before `quasar`). Document position alone cannot
   beat them — moving the stylesheet to `<body>` does not help.
2. **Quasar re-declares its brand colours on `.body--dark`.** Overriding
   `--q-primary` & co. on `:root` is not enough; the `.body--dark` block must
   repeat them.
3. **Quasar's switch colours the thumb via `.q-toggle__thumb:after`** and the
   track via `currentColor` — target those, not `.q-toggle__thumb`.

## Design Principles
1. Quiet chrome — the chart and its diff are the hero; UI furniture recedes.
2. Legibility of diffs and data above all: mono + tabular numerals + real
   contrast ratios; status colour always paired with shape/text, never alone.
3. Hairlines and whitespace over boxes; no nested cards, no shadows.
4. Every state change is visible (running, AI up/down, watcher on/off) with
   instrument-grade restraint.
5. Accessibility: visible focus rings, ≥4.5:1 text contrast, ≥44px touch targets
   on mobile, `prefers-reduced-motion` respected, keyboard paths preserved.
6. Responsive: horizontal mono text nav on desktop; drawer plus stacked controls
   on narrow screens. One component, two presentations.

## Known deviations (deliberate)
- **Toasts are kept**, restyled flat/square/mono with a status-coloured left
  bar. The ~120 `ui.notify` call sites are functional feedback; converting them
  all to inline `[SAVED]` text was out of scope for a visual pass.
- **Material Icons remain** on buttons and section headings (small, monochrome).
  Navigation carries no icons — it is pure typography, per the system.
- **Status tags** use a small square indicator rather than an icon.
