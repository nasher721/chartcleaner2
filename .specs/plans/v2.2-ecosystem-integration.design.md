behind a clear seam, with graceful degradation when an optional dependency is
missing (the frozen .app must never hard-require the heavy ones).

## Dependency tiers

- **Core (requirements.txt, bundled in the .app):** `watchdog`, `PyMuPDF`
  (import name `fitz`, PDF text extraction). ex4nicegui is core-if-compatible;
  the app works without it.
- **Optional engines (auto-detected via `importlib.util.find_spec`, never
  required):** `markitdown`, `docling`, `ocrmypdf` (or `ocrmypdf` CLI on PATH),
  `medspacy`. Settings shows a "Converters & optional engines" status card.
- Not vendored: presidio-research (concept only), philter-ucsf (rules ported by
  hand into a pack; no runtime dependency).

## Module design

### `chartcleaner/ingest.py`
`load_file(path) -> IngestResult{ text, engine, warnings }`.
- `.txt/.md` → read as UTF-8 (replace errors).
- `.docx` → stdlib zipfile + word/document.xml text extraction (docx2md-style,
  zero-dep); if `markitdown` installed, prefer it (tables/headings preserved).
- `.pdf` → PyMuPDF text per page; if a page yields ~no text and OCR is
  available (`ocrmypdf` import or CLI), rasterize+OCR the file to a temp
  searchable PDF first. If `markitdown` or `docling` is installed they may take
  precedence via config `ingest.engine: auto|builtin|markitdown|docling`.
- PDF outputs pass through `strip_pdf_furniture()`: drops first/last lines
  repeated across ≥ 3 pages (running headers/footers, page numbers) and
  normalizes `#`/`##` markdown headings to plain text (pdfmd-inspired).
- `converters_status() -> dict` for the Settings card.

### Rule packs (`chartcleaner/rulepacks.py` + `chartcleaner/packs/*.json`)
A pack = `{"_pack": {name, description, source, version}, **config-keys}`.
`list_packs()`, `install_pack(name) -> preset name` (copies config into
`presets/`, stripping `_pack`), `apply_pack(name)` (validate then write
config.json). Shipped packs:
- `Pack – HIPAA Safe Harbor (strict).json` — redactable-inspired strict set.
- `Pack – Philter core PHI (UCSF-inspired).json` — dates, phones, MRN/account
  numbers, emails, URLs, ages > 89, SSN, institution lines. Attributed to
  Norgeot et al., npj Digit. Med. 2020 in `_pack.source`.

### Reversible tokenization (`chartcleaner/tokens.py`, engine stage `tokenize_phi`)
- New builtin stage (id `tokenize_phi`, default **disabled**) between
  `nlp_redaction` and `literal_replacements`.
- Detection reuses `epic_phi_patterns` regexes + `label: value` lines; replaces
  each distinct PHI string with `[[T1]]`, `[[T2]]` … (same value ⇒ same token).
- Mapping is returned in `StageStat.details["token_map"]`; `RunResult
  .to_history_dict()` strips it (counts only) so stats.jsonl stays small.
- App persists maps to `data/tokens/tokens-<ts>.json` after each run
  (`store.save_token_map` / `list_token_maps` / `load_token_map`).
- `tokens.untokenize(text, mapping)` restores. CLI: `clean-chart --untoken
  [file|-]` (clipboard default, newest map unless `--tokens-file`).
- Config section `tokenization: {enabled, prefix}`; `validate_config` extended.

### medspaCy provider (`chartcleaner/nlp_medspacy.py`)
`medspacy_available()`; `detect_sections(text) -> list[(title, start)]` built
on medspaCy's Sectionizer. The `headers` stage uses it when available AND
config `headers_engine: regex|medspacy` (default `regex`); detected titles are
promoted to `## Title`. Falls back silently to the shipped header regex list.

### Evaluation (`chartcleaner/evaluate.py` + `chartcleaner/benchmark.py`)
- Sample set: `[{"name","text","phi":[{"type","value"}]}]`.
- `evaluate(config, samples)` runs the pipeline per sample; an item counts as
  **caught** when its value no longer appears in the output. Reports
  per-type and overall recall + missed-item list. Results cached in
  `data/evaluation.json` for the Stats page.
- `benchmark.generate(n, seed)` builds synthetic Epic-style notes with known
  PHI (names, MRNs, DOBs, phones, emails, SSNs, URLs, addresses, ages>89) —
  asq-phi-inspired safe-handoff checks. CLI `clean-chart --evaluate [N]`.

### Folder watcher (`chartcleaner/watcher.py`)
`FolderWatcher(spec)` on watchdog Observer; debounce 1.0 s per file; input
exts from spec; output `<stem>_cleaned.txt` into out dir (never the watched
dir), run history tagged `watch:<folder>`; status dict for the Settings card
(state, last file, processed count, errors). Config `data/watch.json`.
CLI: `clean-chart --watch DIR [--out DIR]`.

## App wiring

- Clean page: upload accepts `.docx/.pdf/.md/.txt`; ingest runs in a thread;
  toast names the engine used. Batch folder globs docx/pdf too.
- Pipeline page: tokenize stage editor (enable + token prefix); Rule packs
  expansion (install as preset / apply now).
- Stats page: Evaluation expansion — Run benchmark (N) button, recall chips
  + missed-items table from `data/evaluation.json`.
- Settings: converters/engines status card; Folder watcher card; Token maps
  card (list/restore/open/delete); "Ideas" card replaced by shipped-features
  note.
- ex4nicegui (if importable): reactive live chars/words counter under the
  Clean input; plain fallback otherwise.

## Out of scope

macOS code signing/notarization, weekly summary e-mail, recent-runs re-run
(shipped list stays on the roadmap). docling/OCRmyPDF are not auto-installed
(torch / tesseract size); they are detected and documented.
